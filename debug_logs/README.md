# 调试日志

从 2026-11-14 起按调试日期归档。每次调试结束同步当天新增日志及相关代码，保留已归档日期，不导入更早历史。

- `race_logs/`：比赛步骤、参数快照、识别结果和发射时刻照片。
- `startup_logs/`：单终端脚本的 ROS master 和硬件启动日志。
- `ros_logs/`：当天创建的 ROS 会话原始日志。
- `manifest.json`：车端快照文件路径、字节数和 SHA-256。`code/` 前缀对应仓库根目录；该清单描述同步时的车端文件，不包含随后新增的仓库文档和测试。

日志同步前扫描凭据。`sent=True` 仅表示发射指令发送结果，不能单独证明实际出弹或击倒目标。部分日志为空或被截断，按车端原样保留，不据此认定步骤成功。
